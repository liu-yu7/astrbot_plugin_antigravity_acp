# 上下文窗口与补丁

## 两个限制需要同时设置

AstrBot 模型条目的 `max_context_tokens` 告诉框架何时截断 / 压缩历史；官方 agy 自己还有上下文选择和 checkpoint 限制。只修改其中一个数字不能证明另一个限制已改变。

本插件将设置联动到：

1. 本适配器现有模型条目的持久化配置与运行中副本。
2. 隔离 home 下的 `agy/settings.json` 和 `antigravity-cli/settings.json` 的 `contextWindow`。
3. 重建会话时的文本历史回放预算。
4. 六处必需补丁状态的只读检查。

## 窗口语义

| 插件选项 | AstrBot 声明的预算 | 补丁要求 |
|---|---|---|
| `256K` | 256,000 tokens | 不要求确认完整补丁 |
| `512K`（默认） | 512,000 tokens | 六处补丁全部通过检查 |
| `900K` | 900,000 tokens | 六处补丁全部通过检查 |
| `Default` | 完整补丁下 983,040；否则 256,000 | 大回放预算仍要求完整补丁 |

K 按 1000 计。`Default` 会将 agy 的窗口选择写为空串；983,040 是面向 1M Gemini 模型、预留 64K 输出后的保守声明，不是每种模型的服务端能力保证。GPT-OSS 模型条目的声明另限制到 128,000。

## 可选社区补丁

来源：[lili-luo/dsh-plugin-bundle / agy-context-unlock](https://github.com/lili-luo/dsh-plugin-bundle/tree/main/agy-context-unlock)。

本插件针对其 commit `0a90ec37c69430608084e33ebc2f891e328c9e89` 的脚本输出格式实现检查。已验证官方 **agy 1.5.5 / Linux arm64**。不要仅凭版本号推断其他二进制也兼容。

脚本不随本插件分发。请先阅读上游脚本及说明；它修改的是本地官方二进制，而不是普通配置文件。退出相应进程、单独备份原文件后，按上游的 dry-run / in-place 流程操作。

插件配置 `patch_script` 可填写已审阅脚本的绝对路径。留空时查找：

```text
~/.gemini/antigravity/tools/agy-patch.py
```

本插件仅执行：

```text
<当前 Python> -I <本地脚本> --binary <agy> --dry-run --no-env-fix
```

- 不下载脚本或 CLI，不安装自动更新任务，不调用 `--in-place`。
- 不依赖可选环境变量补丁。
- 必须看到 Gate 1、2、3A、3B、4A、4B 均已应用，才允许显式 512K / 900K。
- Python 的 `-I` 避免常规路径污染，**不是脚本安全沙箱**。

六处检查覆盖窗口选项、持久化选择、checkpoint 上限 / 实验覆盖和两种用户输入序列化截断。完整补丁也会解除 agy 对单条用户输入的旧 64K clamp；它不改变服务端能力、账号权限或额度。

## 回放预算

`replay_budget_bytes = 0` 自动选择：

- 完整补丁：`min(窗口 tokens × 2, 2_200_000)` 字节。
- 未确认完整补丁：最多 `160_000` 字节。

因此默认 512K 对应 `1_024_000` 字节。正整数可设置更小预算，超过当前安全上限则报错。

历史转录按最近消息优先保留，超出预算时省略早期消息；最近的部分历史图片可重新附加。**它是字节启发式，不是 tokenizer**：图片、工具说明和新输入仍会额外占用模型上下文，不能理解为“保证保留 512K tokens 的所有历史”。原始历史函数仍保留 160,000 字节的保守默认值，运行时会显式传入已验证的预算。

## 保存、重载与升级

WebUI 保存插件设置会热重载插件并停止旧 agy 进程，可能中断当前请求。新进程使用新窗口；模型上限随后自动同步。

`/agy status` 会区分配置选项、通过检查的窗口预算和当前进程窗口。配置错误时不会把仍在运行的旧窗口误报为新窗口已生效。

agy 或检查脚本的文件身份变化会使缓存失效。升级 agy 会覆盖二进制补丁；重新核验并在必要时手动补丁，然后重载插件或执行 `/agy restart`。不能检查时可切回 256K。

未执行 512K 满载测试，不承诺长上下文质量、所有模型容量或所有平台兼容。
